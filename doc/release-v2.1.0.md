# sdMetaImageSorter 2.1.0

直前のリリース **2.0.1b** からの累積リリースです。
「Photoshop／Celsys Studio Paint 等で保存しただけの非AI画像が `webui_img` へ大量に誤仕分けされる」
問題の修正を中核に、分類・抽出・収集/移動/集計の各段を見直しました。

## ハイライト

### 1. 誤検知の解消（今回の主目的）

ツール名や XMP の「存在」だけで AI 生成と判定していた経路を全廃し、**キー＋値のパターン**で
判定するようにしました。実測で 427 枚中 341 枚（80%）が誤検知だった事例は
「PNG の `Software = "Celsys Studio Tool"` だけ」が根拠でしたが、この形では仕分けされなくなります。

- `Software` の**存在**では WebUI にしない（`Software` は AI ツール名の表に一致したときだけシグナル）。
- **XMP の有無**では WebUI にしない（XMP は `AIPromptInformation` / `DigitalSourceType` /
  `CreatorTool` / `UserComment` の値で個別に判定）。
- PNG `Comment` の**存在**では NovelAI にしない（NovelAI 設定 JSON として値検証を通った場合のみ）。
- `Dream` キーの**存在**では InvokeAI にしない（旧式構文の値検証を通った場合のみ）。
- 表示ラベル文字列（`label`）を分類条件に使わない（JPEG COM は fast_meta が渡す構造化された印で判定）。

### 2. 判定手順と弱い証拠の扱い

判定は **SwarmUI → InvokeAI → Easy Diffusion → ComfyUI → NovelAI → WebUI（強・中）→ 弱い証拠の複合**
の順です（上のものが優先）。弱い証拠は次のとおり扱います。

- 弱い証拠（本文の部分一致、Stealth の存在、末尾データ、未証明レコード、JPEG COM の片方マーカー）は
  **同じ方向の異なる種類が 2 つ以上**揃ったときだけ確定に使います。単独では仕分けません。
- WebUI 方向と NovelAI 方向の弱い証拠が同時に成立した場合は NovelAI を優先します。
- ComfyUI 方向の弱い証拠（`"workflow"` の部分一致など）は複合でも確定に使わず、記録のみです。
- Stealth PNG Info は本文の JSON 構造（トップレベル）で判別できれば強い証拠、できなければ弱い証拠です。

### 3. 抽出の堅牢化（内蔵 fast_meta 2.3.0）

- **fail-soft**: TIFF のエントリ破損、PNG の壊れたチャンク、XMP の局所破損があっても、
  後ろにある本物のメタデータを落としません。
- **デコードの対称化**: UTF-16 の XMP、`tEXt`/`zTXt` 格納の XMP、非 UTF-8 の iTXt、
  Latin-1 の TIFF ASCII タグ、`Exif\0\0` 付き WebP EXIF などを読めるようになりました。
- **未証明レコードの隔離**: IEND 到達も CRC 接続証明も無いまま拾った PNG レコードは
  弱い証拠としてのみ扱います（誤分類の種にしません）。
- **Stealth 自動検査**: 「生成内容を担うレコードが 1 件も無いときだけ検査する」に変更しました
  （`Software` / `Title` など付随情報だけの画像でも検査します）。検査は先頭行の解凍で判定するため、
  コスト増は測定限界以下です。

### 4. 収集・移動・集計

- 再帰収集で**シンボリックリンク／ジャンクション**を辿り、実パスの訪問済み集合で循環を防ぎます
  （辿った件数・循環で素通りした件数を別行表示）。
- 入力の**重複を実パスで排除**し、結果を決定的にします（除去件数を別行表示）。
- 存在しない入力は**入力エラー**として集計し、他の入力の処理を継続します。
- 単一ファイル指定時の旧フォルダ移行は、親自身／親直下の旧フォルダに限定します（失敗しても仕分けは継続）。
- 直接指定したファイルにも、走査と同じ拡張子フィルタと出力フォルダ除外を適用します。
- 結果を **{仕分け済み, スキップ（メタデータ無し）, スキップ（dest 同名衝突）, dest 作成不可, エラー}**
  に区別し、合計が入力ファイル総数と一致します。元削除失敗は「仕分け済み」の内訳警告として別行表示します。

### 5. 集計表示（新しくなりました）

```
Total Scanned: N
  -> ComfyUI / WebUI / NovelAI / SwarmUI / InvokeAI
  -> Skipped (no metadata)          ← 旧 "Skipped"
  -> Skipped (dest conflict)        ← 新規（同名衝突で残った件数）
  -> Dest unavailable               ← 新規（出力フォルダを作れなかった件数）
  -> Errors
  -> (warning) Source not removed   ← 新規（仕分け済みだが元が残った件数）
Pre-processing:                     ← 処理前の件数（合計には含めない）
  -> Input errors / Collection errors / Excluded / Duplicate files removed
  -> Links followed / Links skipped (cycle/visited)
```

### 6. 終了コード

| 条件 | 値 |
|---|---|
| フォルダ名引数の検証エラー（空・`.`・`..`・区切り含み・絶対パス・重複） | **2**（1 ファイルも動かさない） |
| ファイル単位のエラー、dest 作成不可、元削除失敗、入力エラー、収集エラー | 1 |
| それ以外（dest 同名衝突はスキップ扱い） | 0 |

## 2.0.1b からの互換性・注意

- **集計表示の行が変わりました**。`Skipped:` 行をパースしている場合は
  `Skipped (no metadata):` へ読み替えてください。
- **終了コード 2** が追加されました（引数検証エラー）。従来は開始前でも 0／1 でした。
- **存在しない入力パス・収集エラー**がある場合の終了コードが 1 になりました（従来は 0 または異常終了）。
- 誤検知が減るため、以前 `webui_img` に入っていた非AI画像（`Software` のみ等）は**仕分けされず
  その場に残ります**。必要に応じて手動で戻してください。
- Stealth PNG Info の扱いが変わりました（構造で判別できなければ弱い証拠）。
  本文に `workflow` を含むだけの Stealth は ComfyUI になりません。
- 分類先フォルダ名（`-c`/`-w`/`-n`/`-s`/`-i`）は処理開始前に検証されます。
- `--copy` の挙動、移動・衝突時の非上書き（`__legacy_*`）は従来どおりです。

## 既知の制限

- **C2PA は未実装**です（宣言だけの画像は仕分けられません）。
- EXIF／XMP パケットが **16MB** を超える場合、その担体は読まれません（資源保護の仕様）。
- 分類に使わない担体（EXIF `Make`/`Artist`/`XPComment`、IPTC Caption、XMP `title`/`description`、
  PNG `Title`/`Source`）は `doc/inventory-261127.md` に棚卸しとして固定しています。

## 検証

- `cargo build --release --locked` / `cargo test --locked`: 緑（unit 22 / integration 17）
- フィクスチャ: 負例 14 件（すべて仕分けられない）＋正例 23 件（すべて期待どおりの行き先）を
  レコード単位で固定。実ファイル経由の統合テスト（Celsys PNG が動かない／正例の回帰／
  IEND 無し PNG／XMP を tEXt に格納した PNG など）も追加。
- 等価性（改修前 main 2.0.1b → 2.1.0）: Phase 0 コーパス 13 件で行き先差分は 2 件のみ
  （`stealth.png`／`trailing.png` が仕分け対象外に）、混合 800 件では汎用レコードのみ 80 件が
  `webui_img` → 仕分けなし。いずれも意図した変更です。
- 性能（メタデータ無し多数派の混合コーパス、3 回計測）: 改修前との差は
  実パス重複排除の 20〜30 µs/件が主因で、Stealth ゲート変更のコストは測定限界以下でした。

## インストール

リリースアセットの `sd_meta_sorter.exe` をダウンロードして実行してください。
fast_meta はライブラリとして内蔵しているため、別途のダウンロードや配置は不要です。
