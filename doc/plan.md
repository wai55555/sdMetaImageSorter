# 改修計画

1. fast_meta のステルス検出出力を分類し、生成元不明は WebUI に整理する。
2. NovelAI を専用フォルダに分類する。
3. 同名の整理先を上書きせず、移動・コピーの失敗を報告する。

各段階を検証して個別にコミットする。ステルス抽出には対応版 fast_meta が必要。

## 検証

`cargo test --locked` で分類と重複時の保護を確認する。`cargo build --release --locked` でビルドを確認する。移動時はハードリンクを優先し、利用できない場合は排他的にコピーしてから元ファイルを削除する。

## 分類の優先順位

NovelAI と ComfyUI は fast_meta の形式見出しを優先して判定する。プロンプトやステルス本文に含まれる一般語だけでは ComfyUI に分類せず、生成元が分からないステルス情報は WebUI に整理する。

## 整理先フォルダ名

既定名は `comfyui_img`、`webui_img`、`NovelAI_img` に統一する。整理前に旧既定名 `webui_image` を `webui_img` へリネームする。NovelAI の旧フォルダ名は未リリースのため移行も走査除外もしない。新旧の両方がある場合は中身を統合し、同名ファイルは上書きせず連番付きの名前で新フォルダ内に保持する。
